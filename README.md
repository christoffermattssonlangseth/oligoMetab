# OligoMetab

Work in progress (2026-09-28): metabolism (ketone bodies, glycolysis / lactate, TCA / OXPHOS, fatty acids, lipids) of oligodendrocytes across the OligoC4b datasets. Same structure as `OligoC4b`; see `scripts/oligometab.py` for the gene panel and `notebooks/src/` for the notebook sources (converted with `scripts/nb_from_py.py`).
